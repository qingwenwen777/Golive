# GoLive Web

`golive-web` is the production frontend for GoLive. Its stack includes Vite, React 18, TypeScript,
TanStack Query, Zustand, React Router, Tailwind CSS, Radix UI, and
`mpegts.js`.

## Features

- Home, search, channel pages, live rooms, and HTTP-FLV playback.
- Sign-in, Google sign-in, account suspension pages, and coin pages.
- Chat WebSocket, gifts, SuperChat, betting, and a recent-chat cache.
- Creator studio: stream preparation, appointments, posts, moderators, fan clubs, replays, and the live console.
- Admin console: dashboard, creator reviews, content moderation, users, streams, revenue, and system status.
- Chinese, English, and Japanese translations, with locally persisted theme and language preferences.

English is the default language, regardless of the browser language. A language chosen by the user
is saved under `golive-lang` in localStorage and restored on subsequent visits.

## Prerequisites

- Node.js >= 20
- pnpm

## Run locally

```sh
pnpm install
pnpm dev
# http://localhost:5173
```

The Vite development server proxies `/api`, `/ws`, and `/live` to local backend ports:

| Path | Target |
| ---- | ---- |
| `/api` | `http://localhost:8080` |
| `/ws` | `http://localhost:8081` |
| `/live` | `http://localhost:8082` |

## Environment variables

| Variable | Description | Typical value |
| ---- | ---- | ------ |
| `VITE_API_BASE` | HTTP API base URL | `/api` |
| `VITE_WS_BASE` | WebSocket base URL | `/ws` |
| `VITE_FLV_BASE` | HTTP-FLV base URL | `/live` |
| `VITE_RTMP_BASE` | OBS publishing URL prefix | `rtmp://localhost/live` |
| `VITE_GOOGLE_CLIENT_ID` | Google Identity Services client ID | See `.env.example` |
| `VITE_TOPUP_CURRENCY` | Currency top-ups are charged in; must match the user-service Stripe currency | `USD` (default) |
| `VITE_COINS_PER_CURRENCY_UNIT` | Coins per currency unit; must match the user-service Stripe rate | `10` (default) |

Production uses same-origin requests by default: nginx serves static files and proxies `/api`, `/ws`, and `/live`.

## Scripts

```sh
pnpm test       # Vitest
pnpm typecheck  # TypeScript project references
pnpm build      # tsc -b && vite build
pnpm lint       # ESLint
pnpm format     # Prettier + Tailwind class sorting
```

## Directory overview

```text
src/
  api/          Backend API wrappers
  components/   Shared components and shadcn/radix primitives
  features/     Live-room, creator, account, media, and other feature components
  hooks/        Shared hooks
  i18n/         en-US / zh-CN / ja-JP translations
  lib/          axios, authentication, CSRF, gift, level, cache, and other utilities
  pages/        Route pages
  stores/       Zustand stores
  styles/       Global and live-room styles
```

Build artifacts, test reports, and local debug logs are generated by the development environment and excluded from version control.
